关于这个榜

三个榜分别是什么、分数怎么算出来、那些数字的出处怎么看。全部用大白话写—— 看完你就知道我们凭什么把某个项目排在前面。

这个网站是什么

它把 GitHub 上的项目挑出一批来，分成三个榜，用大白话告诉你是干什么的、你到底装不装得上。 整站是一堆纯静态网页：没有后台、没有数据库、不用登录，也不会往任何地方发送你的信息。

页面读的是数据文件：先在项目目录里跑一次采集，把当天的情况写成 JSON 文件，页面再把它们显示出来。 所以整站可以原样放到任何静态托管上，也可以只在你自己的电脑上看。 这个网站自己不会去采集：它只是一堆页面，没有后台、也没有任何定时任务。 仓库里另外带了一个可选的每日定时任务（放在 GitHub 上、由你启用）：启用后 GitHub 会替你定时跑一次采集； 不启用、或者你只是在自己电脑上看这一站时，榜单只在你亲手跑一次采集之后才更新。

  • 本站不是 GitHub 官方做的，跟 GitHub 也没有任何关系；名字里带 GitHub，只是因为数据来自那里。
  • 数据来自 GitHub 的公开信息（项目页上人人可见的那些数字）。是谁、什么时候、怎么采集的，这一页下面写清楚了。
  • 我们看不到、也改不了你的电脑（见下面「网站看不到你的电脑」）。

三个榜分别是什么

🔥 本周飙升
过了门槛的项目，按下面那三轴加起来的总分排。回答的是"最近大家在玩什么"。
🌟 新手能玩
同一批项目，换成按"新手友好"那一轴排。回答的是"哪些你今晚真的能装上"。
🏆 经典必玩
只按总收藏人数排的老牌好东西，不算分、也不套门槛（所以里面可能有已经停止维护的老项目）。 它是给刚来的人补课用的：不是"最热"，是"最值得先看"。

新手友好（满分 25）：你真的装得上吗

安装方式（满分 18）
按最容易的一种算，七档：有现成的 Windows 安装包 18 分；一条命令就能跑起来 16 分； 要先装好 Python 再装它 14 分；要先装好 Node、再照说明敲命令 8 分； 只能自己动手编译 6 分；只能在 Docker 里跑 4 分；我们没找到能用的安装方式就是 0 分。
中文说明（满分 7）
这一项要么 7 分、要么 0 分，不按比例给：正文里汉字占比到达标线、或者有一份 中文说明文件（例如 README.zh-CN.md），满足任一就给满 7 分；两样都没有就是 0 分。 非中文的本地化说明不给这一项的分：只有 README.ja.md 这类文档的项目， 这一项是 0 分，也不会挂中文徽章——我们只会照实说"有本地化文档（非中文）"。 （代码里这一项的构成是"正文 4 分 + 本地化文件 3 分"，但两者是同一件事的两种证据， 满足其一就已经给满，所以对外只有 7 或 0 两档。）

卡片上那个「🟢 一键就能玩 / 🟡 要几步 / 🔴 要懂点技术」只看安装方式这一项， 跟热度和口碑无关——它说的是"你要动手到什么程度"，不是"这个项目好不好"。

上榜门槛（只对前两个榜）

「本周飙升」与「新手能玩」里的项目，必须同时满足五条，缺一条就不进榜：

  1. 没有停止维护；
  2. 有开源许可证；
  3. 最近 7 天内有更新；
  4. 总收藏人数不少于 200；
  5. 至少有一条我们核实过的安装方式（现成的 Windows 安装包、一条命令、按官方说明装， 或者项目自己写着要编译 / 要先用 Docker）。

还有一种项目也进不来：只有一份资料清单的（那种"awesome 清单"）。但它不是第六条门槛—— 我们判断"这是资料清单"的前提，就是它连一条能用的安装方式都没有，而那件事已经被第五条挡掉了。 所以它只是给同一批被挡下的项目一句更准确的话，不会让多一个项目落榜。

经典必玩榜不套这些门槛：它就是把总收藏人数最高的项目排出来，好坏你自己看一眼就知道。

「这一周新增收藏」是怎么来的

这个数字最影响热度分。我们按下面的顺序一级一级试，试到哪一级有数据就用哪一级， 用到哪一级、页面上就标哪一级（所以「实测」会出现不止一次——它们量的是不同来源）：

  1. 实测：我们逐日记录的前后两次差值（两次之间隔 7 天以上）。这是最准的一种。
  2. 实测（刚建的项目）：项目建了 7 天以内，那它的总收藏人数本身就是这一周的量。
  3. GitHub 官方数据：GitHub 自己的趋势页面写着这个数字，我们照抄——这是转述，不是我们量出来的。
  4. 实测：当前收藏人数减去 7 天前那一天记下的收藏人数。两次记录正好隔 7 天，与第一级一样， 只不过量的是两个点、而不是一整条逐日记录，所以粒度更粗。（对比用的正是每天那份数据里 7 天前的那一天。 另外我们每次采集还会顺手留一份按月存的归档快照文件，那是留着以后用的，目前没有任何代码读它，也不是这一级的来源。）
  5. 约 N（估算）：从项目公开的活动记录里按时间窗口外推出来的。它是个估算，页面上一定带「约」和「估算」。
  6. 以上都拿不到：我们不写数字，卡片上写"这一周的新增收藏，我们没有查到"。 绝不会用 0 冒充"没涨"——那是我们不知道的事。

页面上三种说法的意思：带「实测」的是量出来的，带「约」和「估算」的是我们推算的， 带「GitHub 官方数据」的是官方页面自己写的。

看到的是演示数据吗

如果你是用 npm run demo 打开的这一站，那么榜单页顶部会写着「这是演示数据（示例），不是刚采集到的真实数据」， 并且说清它代表哪一天。那份数据是内置的样本，用来让你看看这个网站长什么样，不代表最近真的在流行什么。

你自己的数据要用 npm run collect 采集出来（需要联网）。真实数据的页面上不会有那句标注。

网站看不到你的电脑

这一站是纯静态网页：它只会向同一个网站目录要几个数据文件，不会读你电脑上的文件、不会装任何东西、 也不会把任何信息传出去。页面上那些安装命令只是文字——按不按回车、装不装，全由你自己决定。

所以也看不到你的电脑：你装没装 Node、Python，装过什么，页面一概不知道，也不去猜。 要确认，只能你自己在命令行里敲一次 node -v 看一眼（新手准备页里有怎么做）。

我们不承诺的事

  • 榜上的项目都是别人写的公开项目。我们只负责"挑出来、说人话"，没有审计它们的代码， 也不保证它们一定装得上、一定好用。要不要装、装什么，你自己拿主意。
  • 数字是采集那一刻的，不是实时的：这个网站自己不会更新，跑一次采集才会变。你打开页面时看到的数字， 可能已经是几个小时前、甚至几天前采的了（页面上写着它属于哪一天）。
  • 评分口径以后可能调整。真调整了，这一页会跟着改：分数怎么来的，永远以这一页为准。
