新手准备页

从没打开过命令行？照着这一页做一遍就行，大约十分钟。做完再回榜单上复制那行命令。

第 1 步 · 命令行是什么，怎么打开它

命令行就是一个用键盘打字下命令的窗口：没有按钮、没有图标，你打一行字，按回车，它就去干活。 它看起来有点吓人，但你在这一页里只需要做两件事：粘贴一行字、按回车。

在 Windows 上打开它，两种走法任选一种：

  1. 最省事的走法：按键盘左下角的 Windows 键（上面有个窗口图案的那个）， 直接打字输入 PowerShell，屏幕上会出现「Windows PowerShell」，点它（或者按回车）。
  2. 另一种走法：按 Windows 键，输入 cmd，出现「命令提示符」，点它。 这两个窗口都能用，随便哪个都行；下面说到"命令行窗口"时，指的就是它。

打开之后你会看到一个深色（或者黑色）的窗口，里面有一行字，末尾通常是一个 > 号， 后面有个光标在闪。那个光标就是在等你打字。

看到的东西和上面不一样？没关系。只要你面前有一个窗口，里面有一行字和一个在闪的光标， 那就是命令行窗口，可以继续往下做。

第 2 步 · 看看电脑上装没装 Node 和 Python

榜单上的项目，很多需要你的电脑上先有一个免费的小工具才能装。这里介绍两个最常见的： Node.js（念"诺德"）和 Python（念"派森"）。 你不用现在决定装哪个——先照着下面两条命令各敲一遍，看看结果。

怎么敲

在刚打开的那个命令行窗口里，用键盘打上 node -v，然后按回车。 注意中间有个空格；打错了不要紧，重新打一遍就行。

打完按回车之后，会有两种结果：

  • 屏幕上冒出一行像 v22.11.0 这样的东西 —— 说明已经装好了，不用再装。
  • 屏幕上说「不是内部或外部命令」「无法将……识别为 cmdlet」或者类似的英文 —— 说明还没装。去下面「怎么装 Node.js」那一节照做。

Python 也一样

在同一个窗口里打上 python --version，按回车。看到 Python 3.12.4 这样的字就是装好了； 说不认识这个命令就是没装。

怎么装 Node.js

  1. 打开浏览器，访问官方网站：nodejs.org。
  2. 页面上有个大大的绿色按钮，写着 LTS（长期支持版）。点它下载。
  3. 下载下来的是一个 .msi 安装包，双击它，然后一路点「下一步 / Next」，最后点「安装 / Install」。
  4. 装完把命令行窗口关掉再重新打开一次（这一步很关键：老窗口认不出刚装的工具）， 再敲一次 node -v，这次应该就能看到版本号了。

怎么装 Python

  1. 打开官方网站：python.org/downloads。
  2. 点那个黄色的 Download Python 3.x.x 按钮，下载 .exe 安装包。
  3. 双击安装包。第一屏底下有两个小方框，一定要把「Add python.exe to PATH」勾上 （不勾的话，命令行会一直说不认识这个命令），然后点「Install Now」。
  4. 同样关掉命令行窗口再重新打开，敲 python --version 确认。
要不要一次全装？不用。看你想玩的那个项目需要什么就装什么： 项目详情里第 1 步会写"你需要先准备什么"，照着那一句做。

第 3 步 · 榜单上复制的那行命令，粘到哪里

回到榜单，点开一个项目的卡片，第 2 步会给你一行命令，旁边有个「复制这一行」的按钮。流程是这样的：

  1. 在详情里点「复制这一行」。
  2. 切回那个命令行窗口（在任务栏上点它，或者按 Alt 加 Tab 切换）。
  3. 把鼠标点在窗口里面的空白处，然后右键一下 —— 命令就会自己贴进去 （也可以按 Ctrl 加 V）。粘贴时屏幕上会多出一行字，那就是刚才复制的命令。
  4. 按回车。它就开始干活了，屏幕上会滚出一堆字。
最重要的一个坑：命令要粘到那个命令行窗口里面， 不是粘到按 Windows 键出来的搜索框里，也不是粘到浏览器地址栏里。粘错地方它不会理你。

第 4 步 · 怎么看结果，出错了怎么办

  • 成功的样子：字滚完了，最后又回到那个以 > 结尾、光标在闪的状态， 中间可能出现「added 1 package」这类英文。这就装好了。
  • 看起来像失败的样子：满屏红字，或者停在某一行不动了、一直在转。 先别慌，也别乱点。
  • 想让它停下来：在那个窗口里按 Ctrl 加 C（也就是按住 Ctrl 再按 C）。

报错了怎么办？把红字整段选中复制下来（在窗口里按住鼠标左键拖过那些字，然后按回车或右键复制）， 连同项目名字一起，粘到搜索引擎或者 AI 助手里问："我在装某某项目，出现了这些字，怎么办"。 看不懂之前，不要随手点"允许"或者关掉杀毒软件。

几句大实话：
  • 这些东西都是免费的公开项目。不要为装它付钱，也不要在别的网站下载安装包——只按项目详情里给的那个官方地址下载。
  • 命令行只看你打进去的字，它不会自己乱动你的文件。但"复制别人的命令就按回车"这件事本身要谨慎： 只粘你在这个榜单的项目详情里看到的、或者你信得过的人给你的命令。
  • 网站看不到你的电脑（它是纯静态的，没有这个能力），所以"你装没装 Node / Python"只能靠你自己敲上面那两条命令确认。
  • 实在做不下去也没关系：先把项目主页收藏起来，过一阵再来。榜单上的数据是可以随时重新采集的。

还是不会？三条退路

  1. 把项目详情里第 2 步那一行命令，连同"这是干什么用的"，整段复制给 AI 助手，让它一步一步带着你做。
  2. 先挑标着「🟢 一键就能玩」的项目练手：它们不用命令行，下载下来双击就能用。
  3. 回到榜单，点「🏆 经典必玩」，那些是很多人早就用过的东西，说明和教程通常更多。
